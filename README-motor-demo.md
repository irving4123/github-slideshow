# 电机带载启动演示系统

## 概述

这是一个完整的电机带载启动演示系统，用于展示不同启动方式的特点和性能。系统包含理论文档、JavaScript模拟程序和可视化界面。

## 功能特性

### 🎯 核心功能
- **多种启动方式**: 软启动、星三角启动、自耦变压器启动、直接启动
- **负载类型模拟**: 恒转矩、变转矩、恒功率负载
- **实时监控**: 电压、电流、转速、转矩、温度等参数
- **保护功能**: 过流保护、过载保护、过温保护
- **可视化界面**: 实时曲线图、状态显示、运行日志

### 📊 技术特点
- **真实模拟**: 基于实际电机参数和物理模型
- **实时响应**: 100ms更新频率的实时监控
- **交互式操作**: 可视化控制界面
- **数据记录**: 完整的运行日志和曲线记录

## 快速开始

### 1. 打开演示界面
直接在浏览器中打开 `motor-load-starting-demo.html` 文件。

### 2. 选择启动方式
- **软启动**: 推荐用于大多数应用，启动平稳
- **星三角启动**: 适用于大功率电机，分阶段启动
- **自耦变压器启动**: 多级电压启动，适用于重载
- **直接启动**: 仅用于小功率电机，电流冲击大

### 3. 设置负载类型
- **恒转矩**: 起重机、传送带等
- **变转矩**: 风机、水泵等（推荐）
- **恒功率**: 机床主轴等

### 4. 监控运行状态
- 实时查看电压、电流、转速等参数
- 观察启动过程中的参数变化
- 查看保护功能的工作情况

## 负载特性分析

### 恒转矩负载
- **特点**: 转矩与转速无关
- **应用**: 起重机、传送带、压缩机
- **启动策略**: 软启动或直接启动

### 变转矩负载
- **特点**: 转矩与转速的平方成正比
- **应用**: 风机、水泵、离心机
- **启动策略**: 变频启动效果最佳

### 恒功率负载
- **特点**: 功率恒定，转矩与转速成反比
- **应用**: 机床主轴、卷扬机
- **启动策略**: 需要特殊控制策略

## 保护功能

### 过流保护
- 检测启动和运行过程中的异常电流
- 动作时间：0.1秒
- 保护电机绕组免受损坏

### 过载保护
- 监控长期过载情况
- 动作时间：60秒
- 防止电机过热损坏

### 过温保护
- 监控电机温度
- 最高温度：120°C
- 防止绝缘老化

## 实际应用建议

### 选择启动方式
1. **小功率电机** (< 15kW): 软启动或直接启动
2. **中功率电机** (15-75kW): 软启动或星三角启动
3. **大功率电机** (> 75kW): 变频启动或自耦变压器启动

### 负载匹配
1. **风机水泵**: 优先选择变频启动
2. **传送设备**: 软启动或星三角启动
3. **起重设备**: 需要特殊控制策略

### 保护配置
1. **过流保护**: 设置为额定电流的200%
2. **过载保护**: 设置为额定电流的120%
3. **过温保护**: 设置为120°C

## 故障排除

### 常见问题
1. **启动失败**: 检查负载是否过重，保护设置是否合理
2. **电流过大**: 调整启动时间，检查负载特性
3. **温度过高**: 检查散热条件，调整运行参数

### 调试建议
1. 使用可视化界面观察参数变化
2. 查看运行日志了解故障原因
3. 调整保护参数避免误动作
