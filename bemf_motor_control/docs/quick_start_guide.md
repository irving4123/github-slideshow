# BEMF无传感器电机控制系统 - 快速入门指南

## 1. 准备工作

### 1.1 硬件准备

**必需硬件:**
- 8051增强型MCU开发板
- 三相无刷直流电机
- 功率驱动板 (三相桥式)
- 电源适配器 (12-48V)
- 连接线缆

**可选硬件:**
- 示波器 (调试用)
- 万用表
- USB转串口模块 (调试通信)

### 1.2 软件准备

**开发工具:**
- SDCC编译器
- Keil C51 (可选)
- 串口调试助手
- 烧录工具 (如STC-ISP)

## 2. 硬件连接

### 2.1 详细连接表

| MCU引脚 | 功能 | 连接目标 |
|---------|------|----------|
| P1.0 | PWM_U_HIGH | 驱动板U相上桥臂输入 |
| P1.1 | PWM_U_LOW | 驱动板U相下桥臂输入 |
| P1.2 | PWM_V_HIGH | 驱动板V相上桥臂输入 |
| P1.3 | PWM_V_LOW | 驱动板V相下桥臂输入 |
| P1.4 | PWM_W_HIGH | 驱动板W相上桥臂输入 |
| P1.5 | PWM_W_LOW | 驱动板W相下桥臂输入 |
| P0.0 | BEMF_U | U相BEMF检测点 |
| P0.1 | BEMF_V | V相BEMF检测点 |
| P0.2 | BEMF_W | W相BEMF检测点 |
| P0.3 | CURRENT | 电流传感器输出 |
| P0.4 | VOLTAGE | 电压检测点 |
| P3.0/P3.1 | UART | 调试串口 |

## 3. 软件编译

### 3.1 使用SDCC编译

```bash
# 进入项目目录
cd bemf_motor_control

# 编译项目
make all

# 生成的文件在dist目录下
ls dist/
```

### 3.2 使用Keil C51

1. 打开Keil C51
2. 创建新项目
3. 添加所有.c文件到项目
4. 设置包含路径为`include`目录
5. 编译项目

## 4. 参数配置

### 4.1 基本电机参数

编辑 `include/bemf_config.h` 文件:

```c
// 根据实际电机修改以下参数
#define MOTOR_POLE_PAIRS    4           // 电机极对数
#define STARTUP_DUTY        20          // 启动占空比 (%)
#define MAX_DUTY_CYCLE      90          // 最大占空比 (%)

// BEMF检测参数 (可能需要调整)
#define BEMF_THRESHOLD      512         // BEMF检测阈值
#define BEMF_FILTER_COUNT   3           // 滤波次数
```

### 4.2 保护参数设置

```c
// 根据系统规格设置保护参数
#define MAX_CURRENT         5000        // 最大电流 (mA)
```

## 5. 首次运行

### 5.1 安全检查

**在首次运行前，请务必检查:**

1. ✅ 所有连接正确无误
2. ✅ 电源电压在规定范围内
3. ✅ 电机能够自由转动
4. ✅ 保护参数设置合理
5. ✅ 串口连接正常

### 5.2 上电测试

1. **连接串口调试工具** (波特率9600)
2. **给系统上电**
3. **观察串口输出**，应该看到:
   ```
   BEMF Motor Control System Started
   ```
4. **设置目标转速** (通过修改代码或串口命令)
5. **观察电机启动过程**

### 5.3 预期现象

**正常启动过程:**
1. 系统初始化 (约1秒)
2. 电机对齐 (约50ms)
3. 开环加速 (约100ms)
4. 切换到BEMF控制
5. 稳定运行

**串口输出示例:**
```
BEMF Motor Control System Started
Motor alignment started
Open loop acceleration
BEMF detection enabled
Speed: 1500 RPM, Duty: 45%, State: 2
```

## 6. 常见问题排除

### 6.1 电机不启动

**可能原因及解决方法:**

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 无PWM输出 | 程序未正确运行 | 检查程序下载，重新上电 |
| PWM输出异常 | 硬件连接错误 | 检查PWM引脚连接 |
| 电机抖动 | 相序错误 | 调整电机相序连接 |
| 立即保护 | 保护参数过严 | 适当放宽保护阈值 |

### 6.2 启动后立即停止

**检查步骤:**
1. 查看串口输出的故障信息
2. 检查保护参数设置
3. 确认电机负载不过大
4. 检查电源电压是否稳定

### 6.3 运行不稳定

**调整参数:**
1. 增加BEMF滤波次数
2. 调整BEMF检测阈值
3. 减小启动斜坡时间
4. 检查硬件噪声

## 7. 参数调优

### 7.1 BEMF检测参数

```c
// 如果电机启动困难，尝试调整这些参数
#define BEMF_THRESHOLD      512    // 降低阈值 (如400)
#define BEMF_FILTER_COUNT   3      // 增加滤波 (如5)
#define COMMUTATION_DELAY   30     // 调整延迟 (20-50us)
```

### 7.2 启动参数

```c
// 启动参数优化
#define STARTUP_DUTY        20     // 可适当增减 (15-30%)
#define STARTUP_RAMP_TIME   100    // 可适当延长 (150-200ms)
```

### 7.3 PID参数

在 `src/main.c` 中调整PID参数:

```c
// 速度控制PID参数
int pid_output = (speed_error * 2) +           // 比例项
                 (integral / 10) +             // 积分项  
                 ((speed_error - last_error) * 1); // 微分项
```

4. **保护测试**: 验证各种保护功能

**测试项目:**
