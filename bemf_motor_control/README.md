# 无传感器BEMF电机控制解决方案

基于8051增强型MCU的无传感器BEMF（反电动势）三相无刷直流电机控制系统。

## 系统特性

### 硬件规格
- **MCU核心**: 1T 8051增强型内核，最高24MHz主频
- **存储器**: 18KB Flash ROM, 2KB SRAM, 128B EEPROM
- **模拟前端**: 12位ADC, 2个模拟比较器, 1个运算放大器
- **PWM控制**: 6通道16位专用电机PWM
- **定时器**: 4个16位定时器
- **通信接口**: 2路UART, SPI接口
- **调试接口**: 双两线调试接口
- **硬件加速**: 硬件乘除法器

### 控制特性
- 无传感器BEMF检测
- 六步换相控制
- 软启动功能
- 速度闭环控制
- 过流/过压/过温保护
- 堵转检测与保护

## 工作原理

1. **启动阶段**: 使用开环控制，逐步加速电机
2. **BEMF检测**: 通过ADC和比较器检测反电动势过零点
3. **换相控制**: 基于BEMF信号进行精确的六步换相
4. **速度控制**: 闭环PID控制维持目标转速
5. **保护机制**: 实时监控电流、电压、温度等参数

## 快速开始

1. 配置硬件连接
2. 编译并下载程序到MCU
3. 调整电机参数
4. 启动电机控制

详细使用说明请参考 `docs/` 目录下的技术文档。

## 技术支持

- 支持的电机类型: 三相无刷直流电机
- 控制方式: 六步方波控制
- 反馈方式: 无传感器BEMF检测
- 通信协议: UART/SPI配置和监控
