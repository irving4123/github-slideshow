## 3. 功率驱动电路

### 3.1 推荐功率驱动IC

- **IR2101**: 高压侧/低压侧驱动器
- **IR2110**: 高压侧/低压侧驱动器
- **DRV8301**: 三相栅极驱动器（集成）
- **DRV8323**: 三相栅极驱动器（集成）

### 3.2 功率MOSFET选择

**推荐参数:**
- **Vds**: > 60V (考虑电机反电动势)
- **Id**: > 20A (根据电机额定电流)
- **Rds(on)**: < 10mΩ (降低导通损耗)
- **Qg**: < 50nC (降低开关损耗)

**推荐型号:**
- IRFZ44N (60V/49A)
- IRF3205 (55V/110A)
- IRLB8721 (30V/62A)

### 3.3 栅极驱动电路

```
MCU_PWM ----[R1]----+----[R2]---- MOSFET_Gate
                     |
                   [C1]
                     |
                   GND

R1 = 10Ω (限流电阻)
R2 = 2.2Ω (栅极电阻)
C1 = 1nF (高频滤波)
```

## 4. BEMF检测电路

### 4.1 电压分压网络

```
Motor_Phase ----[R1]----+---- MCU_ADC
                         |
                       [R2]
                         |
                       GND

R1 = 10kΩ
R2 = 10kΩ
分压比 = 1:2 (将电机电压降到MCU可接受范围)
```

### 4.2 滤波电路

```
ADC_Input ----[R3]----+---- MCU_ADC
                       |
                     [C2]
                       |
                     GND

R3 = 1kΩ (抗混叠电阻)
C2 = 100pF (抗混叠电容)
截止频率 ≈ 1.6MHz
```

## 5. 电流检测电路

### 5.1 霍尔电流传感器方案

**推荐传感器:**
- ACS712 (±5A, ±20A, ±30A)
- ACS758 (±50A, ±100A, ±150A, ±200A)

**连接方式:**
```
VCC(5V) ---- ACS712 ---- VCC
GND -------- ACS712 ---- GND
            ACS712_OUT ---- MCU_ADC
```

**输出特性:**
- 零电流输出: 2.5V
- 灵敏度: 100mV/A (ACS712-05)

### 5.2 分流电阻方案

```
Motor_Common ----[Rs]----+---- Power_GND
                          |
                        [R4]----+---- Op_Amp_+
                          |      |
                        [R5]   [C3]
                          |      |
                        GND    GND

Rs = 0.01Ω (分流电阻)
R4, R5 = 10kΩ (偏置电阻)
C3 = 100nF (滤波电容)
```

## 6. 电压检测电路

### 6.1 分压电路

```
VBus ----[R6]----+---- MCU_ADC
                  |
                [R7]
                  |
                GND

设计要求: VBus_max = 48V, MCU_ADC_max = 3.3V
分压比 = 3.3V / 48V ≈ 1:15

选择: R6 = 140kΩ, R7 = 10kΩ
实际分压比 = 10k / (140k + 10k) = 1:15
```

### 6.2 保护电路

```
VBus ----[F1]----[R6]----[D1]----+---- MCU_ADC
                                  |
                                [R7]
                                  |
                                GND

F1 = 保险丝 (1A)
D1 = 齐纳二极管 (3.6V) - 过压保护
```

## 7. 温度检测电路

### 7.1 NTC热敏电阻方案

```
VCC(3.3V) ----[R8]----+---- MCU_ADC
                       |
                     [NTC]
                       |
                     GND

R8 = 10kΩ (上拉电阻)
NTC = 10kΩ@25°C (B值3950K)
```

### 7.2 温度计算公式

```c
// 简化的温度计算
float calculate_temperature(uint16_t adc_value) {
    float voltage = (float)adc_value * 3.3f / 4096.0f;
    float resistance = 10000.0f * voltage / (3.3f - voltage);
    
    // 使用B值公式计算温度
    float temperature = 1.0f / (1.0f/298.15f + log(resistance/10000.0f)/3950.0f) - 273.15f;
    
    return temperature;
}
```

```
VBus(12-48V) ----[Buck变换器]---- 12V ---- 栅极驱动
                       |
                 [LDO稳压器]---- 5V ---- MCU数字电源
                       |

```

### 8.3 推荐电源IC

- **Buck变换器**: LM2596, MP2315
- **LDO稳压器**: AMS1117, LM1084

## 9. PCB布局建议

### 9.1 布局原则

1. **功率部分与控制部分分离**
2. **模拟地与数字地分离，单点连接**
3. **高频信号走线尽量短**
4. **功率回路面积最小化**

### 9.2 关键信号布线

- **PWM信号**: 走线尽量短，避免串扰
- **BEMF检测**: 远离开关噪声源
- **电流检测**: 差分布线，屏蔽处理
- **晶振信号**: 短距离布线，地包围

### 9.3 热设计

- **功率MOSFET**: 添加散热片或铜箔散热
- **功率驱动IC**: 考虑散热设计
- **电流检测电阻**: 散热设计
